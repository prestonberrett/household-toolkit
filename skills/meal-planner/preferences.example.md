# Dinner Plan Preferences

Sample of what `preferences.md` looks like after first-time setup. The values below are examples; the skill replaces them with your answers.

## Themes

| Day | Theme |
|-----|-------|
| Monday | Stir-Fry |
| Tuesday | Taco |
| Wednesday | Slow Cooker |
| Thursday | Pasta |
| Friday | Pizza |
| Saturday | Grill/Griddle |
| Sunday | Sheet Pan |

Themes are fixed. Recipes within a theme rotate.

## Exclusions

- No mushrooms
- No peanuts (allergy)

## Plan location

- Folder: `C:\Users\you\meals`

Finished plans are saved here as `Meal Plan - [Month Year].md`.

## Recipe sources

Check in this order (relative paths are inside the plan location):

1. `Meals.md` (master list of dishes per theme; one heading per theme, one bullet per dish)
2. Theme files, such as `Taco_Night_Recipes.md`
3. The most recent previous `Meal Plan - ....md`

## Planning

- Default horizon: rest of the current month
- Household size: 4
- Repeat window: 3 weeks
